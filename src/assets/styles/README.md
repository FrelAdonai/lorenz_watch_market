# 📁 assets/styles/

Глобальные стили проекта, организованные по модулям.

## Структура

### 📁 `common/`
**Общие стили и утилиты**

- `variables.scss` - CSS переменные (цвета, размеры, отступы, шрифты)
- `mixins.scss` - SCSS миксины для переиспользования (например, медиа-запросы, анимации)
- `normalize.scss` - нормализация стилей браузера (сброс дефолтных стилей)
- `typography.scss` - стили типографики (заголовки, параграфы, ссылки)
- `spacing.scss` - утилиты для отступов (margin, padding классы)
- `common-selector.scss` - общие селекторы и базовые стили

### 📁 `layout/`
**Стили для макетов**

- `flex.scss` - утилиты для Flexbox (классы для flex-контейнеров)
- `grid.scss` - утилиты для CSS Grid (классы для grid-контейнеров)

### 📁 `ui_common/`
**Общие UI компоненты**

- `icons.scss` - стили для иконок (размеры, цвета, анимации)

### `main.scss`
**Главный файл стилей**

Импортирует все модули стилей. Подключается в `main.ts`.

**Правило:** Все новые глобальные стили должны быть добавлены через `main.scss` или импортированы в соответствующий модуль.
